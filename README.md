# EDURA Documents — Requirements, Designs & Project Plans

This repository contains the specifications, design sheets, architectural decisions, and schedules for the EDURA LMS project.

## Key Files
* `final design document v2.md` — The main Software Requirements (SRS) and Design Specification (SDS) report 
* `2 weeks plan.html` — The day-by-day project development plan
* `development guideline.md` — Development guideline issued by SETU
* `retrospectives/` — Sprint-level evaluation documents (to be added during reviews)
